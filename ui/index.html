How it works

Each sound is built from sound waves in code.

Each part gets its own file. That file is a stem.

All stems line up in time.

A mix is all the stems added together.

A seed makes the same music again, byte for byte.

QC checks each file. It must play, not be silent, and not clip.

Commands agents use

Agents use the same tool from the command line. Copy these:

python3 music_tool.py list --json
python3 music_tool.py render rainy-window --seed 42 --json
python3 music_tool.py make my-track --style lofi --tempo 80 --key "C minor" --bars 8 --seed 7 --json
python3 music_tool.py qc --json

Full agent rules are in AGENTS.md in the repo.
